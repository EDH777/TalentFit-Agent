# 技术名称归一化设计

## 目标

让岗位技能匹配能够识别大小写、全角字符、空格、下划线、连字符和明确别名差异，同时覆盖开发、产品、实施、硬件和采购岗位常见能力，并保留不同技术之间的边界。

## 方案

采用分层归一化：先做 Unicode NFKC、大小写和分隔符清洗，再查显式别名表，最后只使用当前有效简历子段中的直接肯定引用补全技能。别名表位于 `backend/app/core/technology_aliases.py`；岗位能力词表位于 staffing evidence 服务中，新增真实同义写法时只扩展对应表。

不使用模糊距离或向量相似度自动合并技术名，避免把 Spring、Spring Boot、Spring Cloud 等不同能力混为一谈。未知技术保留清洗后的原名，仍可通过明确原文证据参与匹配。

项目经历中明确列出的 `technologies` 与独立技能使用同一归一化函数；否定、他人、团队和无本人归属的技术不会被补入。
